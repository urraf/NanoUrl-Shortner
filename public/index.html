Shorten your links

Paste a long URL to get a short one. Sign up to manage your links and see click stats.

Features

Fast redirects

Short codes are cached in Redis so redirects don't hit the database every time.

Click analytics

See clicks over time, devices, browsers, countries and referrers for each link.

Password & one-time links

Protect a link with a password, or make it stop working after the first click.

QR codes

Generate a QR code for any link and download it as a PNG.

Custom aliases

Pick your own short code, like /my-portfolio (paid plans).

REST API

Everything in the UI is available over the API. Docs are at /api-docs.
